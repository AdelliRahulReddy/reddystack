## Purpose

This file tracks keywords from Semrush exports that are realistic for a new domain and aligned with Reddystack's services.

## Selection Rules

- Database: India
- Preferred KD: 0-25
- Volume: 10+
- Intent: Commercial, Transactional, or buyer-useful Informational
- Keep: website development, website design, landing pages, MVP, web apps, automation, prompt engineering, maintenance, redesign
- Avoid: jobs, internships, courses, templates, random definitions, decorative searches, unrelated cities, unrelated industries, tool/platform navigational terms

## Page Mapping Rules

- One primary keyword cluster per page.
- Put the primary keyword in the title, H1, intro, and meta description naturally.
- Use secondary keywords in H2s, FAQs, and internal anchor text.
- Add internal links from homepage, service pages, portfolio pages, and relevant blog posts.
- Keep copy useful and source-aligned. Do not create thin pages just to place keywords.

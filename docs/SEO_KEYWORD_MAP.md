# SEO keyword map

Researched 2026-09-26 with Semrush (US and UK databases; volumes are monthly searches, KD is keyword difficulty 0–100). Use this to decide which page targets which query. One primary query per page; never create a second page for a query another page already owns.

Rules: no doorway or city pages, no keyword stuffing, no invented results or prices. Prefer honest founder-led terms ("specialist", "consultant") over "agency". Update a page's `updatedAt` only when its content really changes.
